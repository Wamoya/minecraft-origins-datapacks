If you are reading this, you are probably interested on modifying something about this datapack so.. let me help you.

- At data>magic>origins>origin_layers you will find a file for each of the magic abilities this pack provides: glyps, spells and 
cantrips. Here you can reorder the layers, and also remove/add/swap entire abilities.

- The g/s/c before every file name stands for glyph/spell/cantrip.

- There are 3 power files that start with "_" (underscore). These are `origins:simple` power files used only for storing 
some descriptions that are shared between magic abilities.

- At data>magic>powers you'll see that most powers do not contain a name nor description, and also that the files aren't named
with their in-game names.. so here is a tip: Files at data>magic>origins are named exactly the same as the power file they are
associated to, so you can use them to identify each magic ability.



I hope this saves you some time :>
